# Taloja Rentals

A modern property rental website for Taloja, Navi Mumbai. Browse verified 1BHK, 2BHK, 3BHK apartments and commercial spaces.

## Getting Started

```bash
cd taloja-rentals
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Features

- Property search and filtering by type, area, and budget
- Featured rental listings with photos and amenities
- About section highlighting local expertise
- Contact/inquiry form
- Fully responsive mobile-friendly design

## Tech Stack

- React 19 + Vite
- Tailwind CSS v4
