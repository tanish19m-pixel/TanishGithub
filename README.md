# TanishGithub

## Top 1% — Your Taloja Rental Website

**Live site:** https://tanish19m-pixel.github.io/TanishGithub/

A ready-to-use rental marketplace for Taloja, Navi Mumbai. Tenants can search properties, view scores, and contact you via Call or WhatsApp.

### For you (non-technical)

Read **[GETTING_STARTED.md](./GETTING_STARTED.md)** — it explains everything in plain English.

**Quick steps:**
1. Update your phone number in `top1-percent/frontend/src/lib/brand.ts`
2. Merge the pull request on GitHub
3. Share the live link with customers

### Run locally

```bash
cd top1-percent/frontend
npm install
npm run dev
```

Open http://localhost:3000
