# CEXY — Premium T-Shirt Brand

Portfolio website for **CEXY**, a premium t-shirt clothing brand with a bold red and white theme.

## Features

- **Hero section** with brand tagline and stats
- **Product collection** with color filters (White, Red, Black)
- **Product detail modal** with size selection
- **About section** showcasing brand story
- **Why CEXY** features grid
- **Contact form** with product inquiry support
- Fully responsive mobile-first design

## Tech Stack

- React 19 + Vite 8
- Tailwind CSS 4
- Google Fonts (Bebas Neue + Inter)

## Getting Started

```bash
cd cexy
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
npm run preview
```
